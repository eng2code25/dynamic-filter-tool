## Dynamic Search Filter

## What this is
A simple search tool that filters a list in real time as the user types.

## Features
- Real-time filtering
- Case-insensitive search
- "No results" state

## Live link demo
https://dynamic-filter-tool.vercel.app/

## What I learned
- Handling user input events
- String methods (toLowerCase, trim)
- Looping through lists
- Showing/hiding elements dynamically

## Notes
This helped me understand how user input connects directly to UI updates.
